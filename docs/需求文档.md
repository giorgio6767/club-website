# 红十字会学生分会网站 · 需求文档

> 版本：v1.0（M0 定稿）
> 日期：2026-11-01
> 定位：为校红十字会学生分会设计并上线官方网站与业务系统，覆盖内容展示、智能问答、场次制活动报名、桂志愿数据核对与时长结算。

## 1. 系统边界（重要）

本系统与**桂志愿平台（广西志愿服务云平台）**的分工：

| 事项 | 归属 | 说明 |
|---|---|---|
| 志愿者注册、活动报名（官方） | 桂志愿 | 志愿者自行在平台操作 |
| 扫码签到签退（权威时长记录） | 桂志愿 | 不重建，避免两套真相源 |
| 时长认证发放 | 桂志愿 | 本系统不写入桂志愿 |
| 活动发布、场次报名（社团内部） | **本系统** | 替代 QQ 收集表 |
| 现场纸质签名核对 | **本系统** | 录入纸质/现场记录，与桂志愿导出交叉核对 |
| 时长汇总核对、报表 | **本系统** | 替代每月手工跑脚本 |

**集成方式**：以文件为边界，单向桂志愿 → 导出 Excel → 本系统导入。导入层做成可替换（API-ready）：若未来获得官方接口，仅替换数据入口，核对/结算/报表不动。不做桂志愿接口逆向（合规与维护性原因，M0 决策记录）。

## 2. 用户与角色

- **游客/志愿者**：浏览官网、查看活动、报名场次、使用智能问答
- **干事（staff）**：发布活动/新闻、查看报名名单、手动增删报名、导入桂志愿记录、录入纸质核对数据
- **管理员（admin）**：干事权限 + 成员管理 + 角色分配

## 3. 功能清单

### P0 — MVP（M1–M3 期）

| 模块 | 功能 | 端 |
|---|---|---|
| 官网 | 社团介绍、新闻动态（列表/详情）、活动展示 | 手机+电脑响应式 |
| 活动报名 | 管理员上架活动并拆分场次（时间段+地点+岗位+名额，类似电商 SKU）；志愿者多选场次报名，先到先得；**事务防超卖 + 时段冲突校验** | 志愿者侧手机优先 |
| 管理后台 | 登录（JWT）；活动/场次/新闻增删改查；各场次报名名单；手动增删报名记录；报名数据导出固定模板 Excel | PC 优先 |
| 基础设施 | Alembic 迁移、pytest 核心接口覆盖、日志 | — |

### P1 — 智能问答（M4 期）

- 从 club-bot（暖暖）抽离问答核心（kb 检索 + 意图路由 + LLM）为 FastAPI 服务，暴露 `POST /ask`（SSE 流式）
- 网站端右下角问答浮窗，会话历史独立于 QQ 群聊记忆
- 暖暖 `chat.py` 改为调用该接口 → 一套服务、QQ/Web 双入口
- 管理后台"未命中问题"页（接暖暖 D 阶段审核流）
- 语料：现有 kb_docs 社团资料 + 红会急救手册

### P2 — 上线后迭代

- 后段核对结算完整版：导入桂志愿签到签退 Excel（解析/校验/幂等去重）→ 与纸质记录交叉核对 → 异常清单（疑似多签/漏签）→ 时长结算与月度报表（窗口函数）
- 检索升级：jieba 关键词 → 向量检索，用 eval_questions.json 做前后评测
- PostgreSQL 排他约束（EXCLUDE USING gist）保证"同人时段不重叠"下沉到数据库
- 自定义导出模板、Redis 限流/缓存

### 明确不做

- 论坛、多人博客、微信小程序、原生 App
- 替代桂志愿的扫码签到与时长认证
- 桂志愿接口逆向

## 4. 非功能需求

- 响应式：一套代码适配手机/电脑；志愿者流程以手机 + 微信/QQ 内置浏览器为准；管理后台 PC 优先
- 安全：智谱 key 仅存服务端；密码哈希存储；接口鉴权（JWT）
- 部署：先 Vercel（前端）+ Render 免费层（后端）验证，M3 迁国内学生机 + 备案域名（域名备案 M0 即启动）

## 5. 里程碑

| 里程碑 | 周期 | 验收 |
|---|---|---|
| M0 骨架 | 1–2 天 | 仓库+文档+可跑骨架 ✓ |

| M2 前端 | W04–W05 | 官网+报名+后台，手机实测通过 |
| M3 部署 | W06 | 上线，社团真实使用 |
| M4 问答 | W07–W08 | Web/QQ 双入口问答 |
| M5 迭代 | W09+ | 核对结算完整版 / 向量检索评测 |

## 6. 简历口径（定稿）

> 为校红十字会学生分会设计并上线官方网站与业务系统（FastAPI + Next.js + PostgreSQL），覆盖场次制活动报名（事务防超卖、时段冲突校验）、桂志愿数据核对与时长结算（Excel 批量导入、窗口函数报表、Alembic 迁移），与桂志愿平台以导出文件为集成边界（导入层 API-ready），并实现 RAG 智能问答的 QQ/Web 双入口服务。
